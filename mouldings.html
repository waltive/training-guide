SPC Decorative Mouldings

The finishing system that completes every wall panel installation — five profile families, all 2.9m lengths.

About Specs Packaging Pricing Applications Talking Points
Home›SPC Decorative Mouldings

What it is: SPC extruded profiles that finish and frame wall panel installations. Five profile families: M-series Door Casings, N-series Decorative Mouldings, D-series Ceiling Lines, T-series Skirting, and BS-series Corner Mouldings. All 2900mm length, MOQ 1500m per item.

Canton Fair Talking Points

  • Complete system seller — customers buying wall boards need mouldings; always quote them together
  • Code = width — M0040 = 40mm, T150 = 150mm, BS650 = 50×50mm corner. Easy to decode
  • MOQ 1500m per item — about 517 pieces. Low enough for distributors to stock
  • SPC mouldings match SPC boards — same material, same film options, same fire rating
  • T801 is a special thin skirting — 80×10mm, only 0.56kg, popular for modern minimal interiors
